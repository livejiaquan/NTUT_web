# NTUT 公共 Wi-Fi 資安宣導網站

![Project Status](https://img.shields.io/badge/Status-Active-success)
![University](https://img.shields.io/badge/NTUT-%E5%8C%97%E7%A7%91%E5%A4%A7-blue)
![License](https://img.shields.io/badge/License-MIT-green)

國立臺北科技大學資訊安全宣導專案，旨在提升校園師生對於公共 Wi-Fi 使用安全意識，提供實用的檢查清單與防護建議。網站採用簡潔清晰的響應式設計，確保在不同裝置上皆能獲得良好的閱讀體驗。

![Website Preview](pictures/home.png)

## 功能特色 (Features)

- **響應式網頁設計 (RWD)**：基於 Bootstrap 4 框架，完美支援桌面、平板與手機瀏覽。
- **直觀的導覽結構**：包含主頁、資安宣導、常見問題 (FAQ) 與聯絡我們等核心區塊。
- **視覺化教學**：運用圖示與簡潔排版，將複雜的資安概念轉化為易懂的圖文資訊。
- **互動式元素**：導覽列與按鈕具備舒適的互動回饋，提升使用者體驗。

## 技術棧 (Tech Stack)

- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Framework**: Bootstrap 4.3.1
- **Icons**: FontAwesome 5
- **Fonts**: Noto Sans TC (Google Fonts)

## 專案結構 (Structure)

```
NTUT_web/
├── css/
│   └── style.css       # 全站樣式表
├── js/
│   └── script.js       # 互動邏輯與特效
├── pictures/           # 圖片資源
├── index.html          # 首頁
└── README.md           # 專案說明文件
```

## 快速開始 (Installation)

1. **克隆專案 (Clone Repository)**

   ```bash
   git clone https://github.com/livejiaquan/NTUT_web.git
   ```

2. **開啟網頁**

   直接使用瀏覽器開啟 `index.html`，或使用 VS Code 的 Live Server 擴充功能啟動以獲得最佳體驗。
